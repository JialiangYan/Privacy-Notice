# QuickNews: iOS Privacy Notice Simulator

This repository contains the simulation web app used in the study *"When Privacy Notices Matter: Investigating the Impact of Timing on the Salience of iOS App Privacy Notices"*

## Overview
The app is a high-fidelity animated and interactive web app that simulates the iOS app installation-to-usage journey. It tests how different timings of privacy notices affect user recall and satisfaction. It features a fictional news app called "QuickNews" and includes 9 different timing conditions for displaying iOS App Privacy Labels (APL).

## Tech Stack
* **Front-end:** React
* **Back-end:** Express.js
* **Database:** MongoDB

## Key Features
* **App Store Simulation:** Mimics the iOS App Store product page, including standard and prominent privacy label placements.
* **Fictional News App:** Distractor task with readable news articles.
* **Device Filtering:** Automatically restricts access to iPhone users to maintain simulation immersion.
